# GitHub Explorer

A simple and responsive web application that allows users to explore GitHub profiles and repositories using the GitHub REST API.

## Features

- Search GitHub users by username.
- Display profile information such as avatar, name, bio, portfolio, and account creation date.
- Show the latest 5 repositories of a user.
- Display repository details including language, stars, and last updated date.
- Handle loading states and invalid usernames.
- Battle Mode to compare two GitHub users based on their repository stars.
- Responsive dark-themed user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- GitHub REST API
- Fetch API
